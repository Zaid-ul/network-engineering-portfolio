## 📁 Projects

### Project 01: Small Office Network Design and Implementation

**Status:** Completed

Designed and implemented a simulated small-office network consisting of two departments: Human Resources (HR) and Information Technology (IT).

**Key implementations:**
- VLAN creation and configuration.
- Switch access-port assignment.
- IEEE 802.1Q trunk configuration.
- Router-on-a-Stick implementation.
- Inter-VLAN routing.
- IPv4 addressing.
- Network connectivity testing.

**Equipment:** Cisco 2911 Router, Cisco 2960 Switch and four PCs.

## 📈 Learning Approach

I follow a practical learning process:

1. Understand the networking concept.
2. Design the network topology.
3. Configure the required devices.
4. Test network functionality.
5. Troubleshoot identified issues.
6. Document the implementation and results.

Each project is intended to demonstrate practical understanding rather than simply reproduce configurations.
